# 宇宙服・梯子横移動・正解演出 — 修正記録

## 実装範囲

- 自作の白＋シアンの宇宙服、黒い不透明バイザー、手袋・ブーツ・背面パック。ゲーム中は顔とポニーテールをヘルメット内に隠します。
- 正解時にヘルメットを持ち上げ、脇に抱える動作。顔・ポニーテールを見せ、笑顔とガッツポーズを継続。リトライ時は着用状態へ戻します。
- 梯子上のA/D・左右矢印は横移動。高さを保持し、未接続の端で停止。上下＋左右の同時入力が可能。離脱はジャンプまたは上下端到達です。
- 接触する隣接梯子への補間移動と90°コーナー接続に対応。既存31問の配置は変更していません。角のある接続は専用のテスト配置で検証しています。離れた梯子へのワープはしません。
- 星空、青い惑星、鏡面風のグリッド床、現在ステージの完成形、遠景の別ステージ形状を正解シーンに追加。既存結果パネルのボタン・処理は維持し、演出用ロゴだけ追加。
- 縦長画面でキャラクター・完成形・惑星の配置を調整。ステージ開始時に通常カメラ・照明へ復元。

## 品質上の境界

参照画像そのものの高精細3Dモデルではありません。軽量な自作デフォルメモデルです。参照のリアル寄りの顔・髪・布の質感と同等という判定はしていません。惑星の地表も地理的に正確な地球テクスチャではなく、手続き的な表現です。床の反射は低コストの簡易表現で、全面リアルタイム鏡面反射ではありません。

キャラクターは22,040三角形。外部有料モデル・不明ライセンス素材・画像テクスチャの追加なし。細部には低分割の共通形状を使用しています。YouTube公式実機検証・低性能スマホでのFPS保証は別途必要です。

## 検証

- 型検査および63ユニットテスト PASS。既存移動・ステージ検証に加え、梯子左右端の落下防止、斜め昇降、明示的なジャンプ離脱、隣接判定、90°コーナーの移動量と高さ、ヘルメット復元を確認。
- ブラウザで正解の選択からPC／390px縦長結果表示、リトライまで確認。WebGL・ページ実行エラーなし。
- 実ステージで梯子昇降、左右移動、端保持、ジャンプ離脱を確認。
- 前回の通常移動・旋回・反転・カメラ・LOOK UP・壁衝突のブラウザ19項目もPASS。本番ビルド成功（JS 559.12 kB、gzip 145.93 kB。500 kBチャンク警告は残っています）。
- 31問データ、UIController、PlayablesSDKは変更なし。CSS変更は結果演出のロゴのみ。Roblox側に書き込みなし。
