# LOOK UP・Answer Terminal・Explorer・Ladder Catch

## 実装

- LOOK UP：通常の三人称オービットとは別に、頭上（足元 + 1.64）からほぼ真上を見る。天井付近ではカメラ衝突に応じて高さを制限。キャラクターは一時非表示、プレイヤーの衝突・位置はカメラから変更しない。
- 復帰：位置・Quaternion・FOV・モード・Yaw/Pitch・距離を保存。解除直後に保存した姿勢を復元し、その次のフレームから通常追従。LOOK UP中に移動していた場合は通常追従再開時に現在位置へ追従する。
- 回答端末：白い台座・テーブル、シアン縁の薄型傾斜モニター、回転する7 Cube Cross、ANSWERのベクター文字。既存の回答位置とE/Fトリガーは未変更。新たな障害物コライダーは追加しない。
- Explorer：黒い曲面バイザー＋シアンの縁、白いシェル、肩パネル、胸部・バックパックの四角形アクセント、細身のテーパー付き腕脚、肘・膝・手首・手袋・靴底を更新。顔・髪なし。既存の関節とJog/Jump/Ladderアニメーションを維持。
- 空中キャッチ：梯子面から0.48未満、横方向0.78未満、有効高さ、梯子から離れる速度と衝突を判定。約0.12秒で近距離の吸着・身体の向き合わせ。垂直速度・ジャンプ慣性を解除し、LADDERで保持。離脱直後0.5秒のクールダウンを維持。
