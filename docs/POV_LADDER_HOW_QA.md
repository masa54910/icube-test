# POV + Ladder Camera + How To Play i18n

2026-09-12 / READY FOR USER QA

POVのA/Dをturnへ移した後、呼び出し先がturnを処理しないため旋回が失われていた。ゲームの移動処理をThird-personと共用し、POVではPlayer YawをCameraへ同期。Sも既存Third-personと同じ方向転換ルール。

梯子端の回転量をladderCameraDeltaへ分離。身体は梯子正面を保ち、梯子中はカメラの追従を停止。離脱時は現在のカメラ方向へPlayerを合わせる。梯子中の視点モード切替も身体を回さない。

How To Playは元からDOMだったが、本文が日本語固定だった。4項目のDOMカードへ再構成し、9言語の見出し・本文・戻るを辞書化。ページ内Language Selectorで開いたまま切替可能。旧ATTEMPTS図示をDOMから除去。「自由に探索」へ変更。手動選択を再起動時に優先。

- 実Edge、実Gameの梯子中央への初期位置設定フィクスチャ：左右端×2モードでカメラ360°、身体Yawと位置固定、ジャンプ離脱直後Yaw連続。
