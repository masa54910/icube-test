# Cubie pose assets

Source: user-provided `codex-clipboard-d166a324-9f19-48d9-9a76-8d3fc2d1afa2.png` (1536 × 1024).

Eight upper-row images were isolated by hand-traced alpha masks, using `work/extract-poses.py`. No generative model, face retouch, RGB colour edits, or image enlargement was used. The source's seated cube is retained as the seat, not a rectangular background. Lossless WebP decoding was checked against the source crop: zero changed RGB pixels for every pose.

Each image is 192 × 358 pixels, at the original sheet resolution. Total: 665,192 bytes. A higher-resolution transparent original would improve large-display sharpness; the current assets do not claim detail beyond the supplied sheet.

These are user-supplied assets, used as authorized for this project. No third-party asset library was introduced. Ownership/commercial rights of the original supplied image have not been independently verified.

Background presets are original procedural Three.js geometry/shaders. No downloaded planet or nebula imagery or runtime asset API is used.

The original `cubie-correct.png` is preserved for Home and existing references.
